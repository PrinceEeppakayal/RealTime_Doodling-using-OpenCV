# RealTime_Doodling-using-OpenCV

RealTime Doodling using OpenCV is a lightweight Python application that turns your webcam into an interactive sketchpad by using MediaPipe Hands for real-time hand landmark detection and OpenCV for rendering. 

Move your index finger to draw on a persistent canvas, raise the finger above its MCP joint to erase, press d to toggle drawing on/off, and use keys (w, r, g, b, y, p, c, o) to switch colors. 

It’s ideal for demos, quick prototyping, and playful human–computer interaction experiments. — GitHub Copilot Chat Assistant
